# Running Teks (Info)
Fitur running teks saat ini masih merupakan fitur tambahan (dibawah SLider)
Jika ingin merubah datanya : 
1. Masuk kehalaman Admin
2. Pilih Menu : Pengaturan - Widget
3. Tambah Widget dan pastikan Judul widget : Info1 / Info2 / Info3 / Info4
4. Pilih Jenis Widget : Dinamis
5. Masukkan kolom "Isi" dengan tulisan yang ingin ditampilkan (1 Widget untuk 1 kalimat)
6. Simpan
* Jika Judul widget tidak sesuai data tidak muncul, bisa dibuat maksimal 4 widget
